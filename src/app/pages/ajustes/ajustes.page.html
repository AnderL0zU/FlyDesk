Qué datos guardamos

FlyDesk guarda tu nombre de usuario, correo, edad, tus ajustes y el historial de tus vuelos. Todo se almacena solo en tu celular; no lo enviamos a ningún servidor propio.

Servicios externos

Para buscar aeropuertos usamos la API de API Ninjas. A ese servicio solo le enviamos el código del aeropuerto que escribes, nunca tus datos personales.

Permisos del celular

Las notificaciones se usan únicamente para avisarte cuando tu vuelo termina, y la vibración para acompañar el despegue y el aterrizaje. Puedes desactivarlas cuando quieras desde Ajustes.

Borrar tus datos

Puedes eliminar tu historial desde la pestaña Historial. Si desinstalas la app, todos tus datos se borran del celular.

Uso de la app

FlyDesk es una herramienta para ayudarte a concentrarte. Cada sesión de estudio se representa como un vuelo simulado; no se trata de vuelos ni reservas reales.

Tu cuenta

Eres responsable de la información que registras y de mantener segura tu contraseña. La cuenta funciona solo en este celular.

Información de aeropuertos

Los datos de aeropuertos vienen de un servicio externo y las duraciones de vuelo son aproximadas, calculadas a partir de la distancia.

Cambios

Este es un proyecto académico y estos términos pueden cambiar. Si continúas usando la app, aceptas la versión más reciente.
